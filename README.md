
# プロセカ リザルト整理帳

プロジェクトセカイのリザルト画像を読み取り、一覧管理できる静的 Web アプリです。  
GitHub Pages でそのまま公開できる構成にしています。

## できること

- 画像のアップロード
- 自動読み取りと手動登録の切り替え
- タイトル、楽曲レベル、楽曲難易度、各種ミス数、コンボ、スコアの保存
- 楽曲名、読み方、レベルでの検索
- AP済み、FC済みの絞り込み
- ミス数の範囲絞り込み
- 難易度の絞り込み
- 楽曲名順、レベル順、ミス数順、追加日順の並び替え
- 自己ベストのみ表示
- 画像の拡大表示
- 編集、ゴミ箱移動、ゴミ箱からの即時削除
- Google Drive へのアップロード
- ゴミ箱に入れたデータの自動期限切れ削除

## 使い方

1. `index.html` を GitHub Pages で公開します。
2. Google Cloud で OAuth クライアント ID を作成します。
3. アプリの「設定」または左側の入力欄に Client ID を入れます。
4. Google 連携を押してログインします。
5. 画像をアップロードすると読み取り下書きが作成されます。
6. 内容を確認して保存します。

## Google Drive 連携の注意点

- このアプリはブラウザのみで動作する静的構成です。
- Drive への保存は Google Identity Services のアクセストークンを使います。
- 3日後の自動削除は、アプリを開いたタイミングで実行されます。
  常時実行のバックエンドがないため、厳密な時刻保証が必要な場合はサーバー処理が別途必要です。

## GitHub Pages への配置

- このフォルダをそのまま GitHub リポジトリに置きます。
- GitHub Pages の公開元を `main` のルート、または `docs/` に設定します。
- そのまま静的配信で動作します。

## 主要な読み取り範囲

- 左上: タイトル
- タイトル下: 楽曲レベル、楽曲難易度
- 中央左: リザルト
- 中央付近: コンボ

アプリ内でも色付きの枠で確認できます。
