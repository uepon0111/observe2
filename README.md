# リザルト保管庫

プロジェクトセカイのリザルト画像を、ブラウザだけで閲覧・検索・整理できる静的Webアプリです。GitHub Pages にそのまま置ける構成にしています。

## できること

- 画像アップロードと一覧表示
- 画像クリックで拡大表示
- 自動OCRによるタイトル・レベル・難易度・ミス数・コンボの下書き作成
- 手動登録と自動登録の切り替え
- 検索、絞り込み、並び替え
- AP自己ベスト / FC自己ベスト表示
- ゴミ箱管理と期限切れ自動削除
- Google Drive 連携アップロード
- 機種ごとの読み取り範囲登録
- 画像一覧の仮想スクロール

## 配置

GitHub Pages の公開ルートに、次の構成で配置してください。

```text
index.html
assets/
  styles.css
  favicon.svg
js/
  app.js
  db.js
  data.js
  drive.js
  icons.js
  ocr.js
  utils.js
package.json
```

## Google Drive 連携

Google Drive へ保存するには、Google Cloud Console で OAuth クライアント ID を作成し、アプリの公開 URL を許可済みの JavaScript 生成元に登録してください。

アプリ内の「設定」から次を入力します。

- クライアント ID
- API キー
- 保存先フォルダ ID（省略可）

その後、「Drive連携」を押すとログインできます。

## 読み取りの調整

「機種登録」からサンプル画像を入れ、赤・青・緑・橙・紫の範囲を数値で調整できます。保存された範囲は、機種ごとに使い分けられます。

## 補足

- OCR はブラウザ側で実行します。
- 自動読み取りに失敗した場合でも、手動編集して保存できます。
- ゴミ箱に入れたデータは 3 日後に自動で完全削除されます。
